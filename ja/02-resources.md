# リソースと可用性

[目次](README.md) · [認定試験](../certifications/ja/README.md)

サブスクリプションは管理、クォータ、請求の境界になります。管理グループは複数のサブスクリプションに方針を適用します。リソースグループは、寿命や管理単位が関係するリソースをまとめます。Entra テナントは ID のディレクトリです。

グループのリージョンはメタデータの場所であり、中の全リソースの場所を強制しません。可用性ゾーンは同一リージョン内の物理的な分離です。対応はサービスごとに確認します。

**演習：**開発環境と本番環境を分け、共通ネットワークの所有者を決めます。二台あるという説明ではなく、どの障害に耐えられるかを書きましょう。リソース移動は、依存関係や対応条件を確認してから行います。
