# Glosario bilingüe / Bilingual glossary

[Six-language glossary / Glosario en seis idiomas](GLOSSARY-multilingual.md)

| English | Español | Idea |
|---|---|---|
| Workload | Carga de trabajo | Aplicación y recursos necesarios / Application and required resources |
| Tenant | Inquilino o directorio | Directorio de identidades / Identity directory |
| Subscription | Suscripción | Ámbito de administración y facturación / Management and billing boundary |
| Resource group | Grupo de recursos | Recursos con ciclo de vida relacionado / Resources with a related lifecycle |
| Availability zone | Zona de disponibilidad | Aislamiento físico dentro de una región / Physical isolation within a region |
| Scalability | Escalabilidad | Cambiar capacidad / Change capacity |
| Elasticity | Elasticidad | Adaptar recursos a demanda / Adapt resources to demand |
| Throughput | Tasa de procesamiento | Trabajo por unidad de tiempo / Work per unit of time |
| Latency | Latencia | Tiempo de una operación / Time taken by an operation |
| Authentication | Autenticación | Quién eres / Who you are |
| Authorisation | Autorización | Qué puedes hacer / What you can do |
| Scope | Ámbito | Dónde se aplica una asignación / Where an assignment applies |
| Managed identity | Identidad administrada | Identidad de carga gestionada por Azure / Azure-managed workload identity |
| Least privilege | Mínimo privilegio | Solo permisos necesarios / Only required permissions |
| Secret | Secreto | Dato confidencial de acceso / Confidential access information |
| Private endpoint | Punto de conexión privado | Acceso privado a un servicio compatible / Private access to a supported service |
| Redundancy | Redundancia | Copias o componentes para tolerar fallos / Copies or components for fault tolerance |
| Backup | Copia de seguridad | Datos para restauración / Data retained for restoration |
| Failover | Conmutación por error | Cambiar a un componente alternativo / Switch to an alternative component |
| Recovery time objective | Objetivo de tiempo de recuperación | RTO |
| Recovery point objective | Objetivo de punto de recuperación | RPO |
| Idempotency | Idempotencia | Repetir sin duplicar el efecto esperado / Repeat without duplicating the intended effect |
| Dead-letter queue | Cola de mensajes fallidos | Mensajes que requieren tratamiento / Messages requiring attention |
| Infrastructure as code | Infraestructura como código | Definición versionada de infraestructura / Versioned infrastructure definition |
| Configuration drift | Desviación de configuración | Diferencia entre configuración declarada y real / Difference between declared and actual configuration |
| Artifact | Artefacto | Salida versionada de compilación / Versioned build output |
