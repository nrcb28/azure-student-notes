# Fondamenti del cloud

[Indice](README.md) · [[object Object]](../certifications/it/README.md)

Il cloud permette di richiedere risorse tramite software. I server esistono ancora: cambia chi li gestisce. Non significa né costo zero né manutenzione zero.

In **IaaS** gestiamo sistema operativo e applicazioni; con **PaaS** deleghiamo più piattaforma; con **SaaS** utilizziamo un prodotto, ma rimangono responsabilità su identità, dati e impostazioni.

Scalare verticalmente significa aumentare la capacità di un'istanza. Scalare orizzontalmente significa aggiungerne altre. L'elasticità adatta le risorse alla domanda; l'alta disponibilità limita le interruzioni.

**Esempio:** durante gli esami aumentiamo le istanze della nostra app di appunti. Se le sessioni sono soltanto in memoria locale, gli utenti possono perderle. Prima di scalare controlliamo stato, file e connessioni al database.

**Domanda:** la replica sostituisce il backup? No: può propagare una cancellazione.
