# Сети и подключения

[Содержание](README.md) · [[object Object]](../certifications/ru/README.md)

VNet — виртуальная сеть, подсети делят её адресное пространство. NSG фильтруют трафик с учётом состояния соединений. DNS разрешает имена. Разрешённый порт не доказывает, что процесс его слушает.

Пиринг не становится транзитивным автоматически. VPN Gateway обеспечивает шифрованные туннели; ExpressRoute — частное подключение, но не автоматическое сквозное шифрование.

Private endpoint предоставляет доступ к совместимому сервису через частный IP. Отдельно проверяются DNS, маршруты и настройки публичного доступа.

Load Balancer работает с TCP/UDP, Application Gateway — с региональным веб-трафиком, Front Door — с глобальным веб-входом. Traffic Manager выбирает адресата через DNS.

**Диагностика:** имя, полученный IP, маршрут, фильтры, порт, аутентификация и авторизация. Открытие всех портов маскирует причину.

**Вопрос:** почему private endpoint недостаточно? Каждый клиент должен разрешать и достигать частного адреса.
