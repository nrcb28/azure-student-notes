# Тренажёр без Azure

[←](README.md) · [Anki](../flashcards/ru.tsv)

Практикуй40 случаев своего языка, по десять на сертификацию. Достаточно Python3.9+ и стандартной библиотеки. Не нужны облачный аккаунт, внешние пакеты или сеть при использовании.

```bash
python tools/study.py demo --lang ru --exam AZ-104
python tools/study.py study --lang ru --exam AZ-104 --limit 5
```

## 1. Проверь себя

Прочти вопрос, подумай и нажми Enter. Сравни объяснение и оцени: 0 забыл, 1 трудно, 2 хорошо, 3 легко. q выходит; завершённые оценки сохраняются. Это самооценка, не автоматическая проверка и не экзаменационный балл.

## 2. Повторяй трудное

Обычный режим сначала выбирает просроченные, затем новые карточки. weak берёт трудные случаи или историю забывания, random перемешивает. Прогресс разделён по языкам. Написанные ответы не сохраняются.

## 3. Прогресс и план

stats показывает новые, просроченные, закреплённые и забывания по экзаменам. Закрепление — две последовательные оценки минимум2, не готовность к экзамену. plan предлагает около четырёх минут на случай, не прогнозирует реальные сроки.

## 4. Интервалы

0 возвращается через десять минут и сбрасывает серию; 1 завтра и сбрасывает. 2: день, затем три, далее удвоение. 3: четыре дня, затем умножение на2,5, максимум365. Простое собственное правило, не FSRS и не гарантия памяти.

## 5. Экспорт в Anki

Скачай готовые колоды или экспортируй выборку. UTF-8, три столбца: вопрос, объяснение, теги. Прогресс Anki независим. Проверь предпросмотр и сопоставление столбцов.

## 6. Твои данные

Файл .study-progress.json исключён из Git. --progress выбирает другой путь. Атомарная запись защищает от конкурирующих сессий, повреждённый JSON не заменяется. Храни копии для переноса истории.

```bash
python tools/study.py study --lang ru --mode weak --limit 5
python tools/study.py stats --lang ru
python tools/study.py plan --lang ru --days 7 --minutes 20
python tools/study.py export --lang ru --exam AZ-104 --output exports/ru-az104.tsv
python tools/study.py doctor --lang ru
```
