# Мини-тест: принимать решения и разбирать ошибки

[←](README.md) · [CLI](../QUIZ.md) · [Читать вопросы на GitHub](20-quiz-cases.md)

32 авторских сценария помогают обосновывать решения в Azure: по два для каждого из [шестнадцати маршрутов](../certifications/ru/README.md). Вопросы, ответы и объяснения доступны на восьми языках — всего 256 языковых вариантов. Инструмент работает локально с Python, без учётной записи Azure и дополнительных пакетов.

## Начало

Python 3.9+ · es / en / it / de / fr / ru / ja / zh

```bash
python tools/quiz.py demo --lang ru
python tools/quiz.py run --lang ru --exam AZ-104 --count 2
```

Без --count выбирается до восьми доступных сценариев. Используй --count 32 без фильтра по экзамену, чтобы пройти весь банк; в каждом отдельном маршруте по два сценария.

```bash
python tools/quiz.py run --lang ru --mode exam --count 32
```

24 добавленных сценария ссылаются на руководства по сертификации на том же языке, например [AI-103](../certifications/ru/AI-103.md). Восемь исходных сохраняют ссылки на главы. Отчёты, сохранённые до расширения, остаются совместимыми: review использует копии вопросов и ссылок из каждого отчёта.

## Практика с объяснениями

В режиме практики объяснение появляется сразу после ответа. Ты увидишь не только правильное решение, но и причину, по которой выбранный тобой другой вариант не подходит к условиям. A–D выбирает ответ, S или пустой ввод пропускает вопрос, Q завершает сеанс. Порядок вопросов и вариантов перемешивается.

```bash
python tools/quiz.py run --lang ru --exam AZ-900 --exam AZ-104 --count 4 --seed 42
```

## Режим экзамена с необязательным таймером

В экзаменационном режиме объяснения показываются только после окончания сеанса. Можно выбрать сертификационный маршрут и при желании задать лимит времени в минутах. Ввод синхронный: таймер проверяется только после Enter и отклоняет запоздавший ответ. Самостоятельно прервать ожидание ввода он не может.

```bash
python tools/quiz.py run --lang ru --mode exam --count 8 --minutes 12 --report .study-reports/first-quiz.json
```

## Разбор ошибок

Сохранённый отчёт показывает верные, неверные и оставленные без ответа вопросы, а также результаты по темам. При повторном разборе по умолчанию выводятся ошибки и пропущенные вопросы с объяснением, источником и подходящей главой или руководством по сертификации. Вопросы без ответа входят в общее число, поэтому раннее завершение не улучшает результат искусственно.

```bash
python tools/quiz.py review --lang ru --report .study-reports/first-quiz.json
python tools/quiz.py review --lang ru --report .study-reports/first-quiz.json --all
python tools/quiz.py review --lang ru --report .study-reports/first-quiz.json --json
```

## Личные отчёты

Отчёты остаются локально в формате JSON в папке .study-reports/, исключённой из Git. В них сохраняется снимок вопросов, порядка вариантов, выбранных ответов и объяснений, поэтому последующие изменения банка не меняют старые сеансы. Инструмент не создаёт ресурсы Azure и никуда не отправляет ответы. Перед публикацией файлов из самостоятельно выбранной папки проверь их содержимое.

## Что означает результат

Два сценария на маршрут — это мини-тест для повторения, а не полная симуляция, официальный набор вопросов или прогноз сдачи экзамена. В объяснениях есть ссылки на англоязычные страницы Microsoft Learn и соответствующие главы или руководства по сертификации этой версии конспекта. Хороший результат говорит только об ответах на эти конкретные учебные вопросы.

```bash
python tools/quiz.py doctor --lang ru
```
