# Вычисления и контейнеры

[Содержание](README.md) · [Сертификации](../certifications/ru/README.md)

VM подходит для контроля ОС, App Service — для совместимого веб-приложения, Functions — для кода по событиям. Container Instances и Container Apps запускают контейнеры без самостоятельного сопровождения кластера Kubernetes. AKS нужен, когда требования оправдывают Kubernetes и эксплуатационные затраты.

Контейнер — не полноценная VM. У serverless остаются ограничения запуска, времени выполнения, сети и стоимости, зависящие от плана.

**Диагностика:** контейнер запустился, но запросы не проходят. Проверяем порт, процесс, настройки, журналы и проверки работоспособности, затем полный запрос с зависимостями.

Отделяем образ от конфигурации. Не помещаем секреты в слои образа. Фиксированную версию проще воспроизвести, чем изменяемый тег latest.

**Задание:** обоснуй выбор AKS или более простой платформы для небольшой API.
