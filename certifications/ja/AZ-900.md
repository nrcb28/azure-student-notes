# AZ-900 · 認定試験

[目次](README.md) · [English](../en/AZ-900.md)

試験分野と比率は、2026年10月27日に確認した英語の公式ガイドに基づきます。試験の言語や実施日により変更があるため、受験前に確認してください。独自の学習用解説であり、すべての出題を網羅すると保証しません。

## 学習の狙い

製品名よりも、どんな要件で選ぶかを説明します。クラウド概念 25–30%、アーキテクチャとサービス 35–40%、管理とガバナンス 30–35%。参照した目標は2026年7月20日からです。

## 責任とサービス

CapEx は資本的支出、OpEx は運用支出です。クラウド化しても人員、ライセンス、契約が消えるわけではありません。

IaaS、PaaS、SaaS ごとに自分の責任を列挙します。Linux カーネルの変更が必要なら VM を検討しますが、普通の Web API なら PaaS が管理を減らせます。

リージョン、ゾーン、サブスクリプション、グループの役割を区別します。Availability set と複数リージョンは同じではありません。Azure Virtual Desktop は仮想デスクトップ用途です。

## データ、ID、管理

Blob、Files、Disks の用途を比較します。AzCopy は転送の自動化、Storage Explorer は GUI、File Sync は対応する環境の同期とキャッシュです。Azure Migrate と Data Box の役割も区別します。

SSO、MFA、パスワードレスは認可の代わりになりません。RBAC は操作の権限、Policy は条件、タグは分類、ロックは管理操作の保護です。

Advisor は推奨、Monitor は観測、Service Health はサービスの問題を扱います。予算はすべての費用を止める機能ではありません。

**提出物：**ノートアプリを描き、計算、保存、ID、方針、費用を選ぶ理由を書きます。五つの費用要因と、設計が耐えられる一つの障害を説明します。
