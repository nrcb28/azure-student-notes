# AZ-104 · 認定試験

[目次](README.md) · [English](../en/AZ-104.md)

試験分野と比率は、2026年10月27日に確認した英語の公式ガイドに基づきます。試験の言語や実施日により変更があるため、受験前に確認してください。独自の学習用解説であり、すべての出題を網羅すると保証しません。

## 学習の狙い

管理者は設定、結果の予測、確認、診断を行います。ID とガバナンス 20–25%、保存 15–20%、計算 20–25%、ネットワーク 15–20%、監視と保守 10–15%。目標は2026年4月17日からです。

## ID とガバナンス

Entra のディレクトリロールと Azure RBAC を混同しません。ユーザー管理者がサブスクリプション Owner とは限りません。

アクセスが残る場合は実際の ID、グループ、直接と継承の割り当てを確認します。NotActions は全体的な拒否ではなく、別のロールから許可される可能性があります。

Policy は小さい範囲で監査し、修復に必要な ID と権限を確認します。Deny だけで既存設定は直りません。

## 保存、計算、ネットワーク

ネットワーク、認証、データ認可を分けます。Contributor が Blob を読めるとは限りません。SAS の種類によって期限と取り消し方法が異なります。バージョンと保持期間を設計します。

VM のサイズ、ディスク、NIC、経路を把握し、一時ディスクに永続性を期待しません。App Service のドメイン、DNS、証明書、TLS を別に確認します。Slot は依存先を共有する場合があります。

VNet integration は送信のためで、受信を自動で非公開にはしません。NSG の小さい優先度番号が先です。Load Balancer では frontend、backend、規則、probe を調べます。

## 保守と演習

ログの収集先、信号、アラート、action group を確認します。バックアップの成功だけで RTO を保証せず、復元全体を測ります。Vault の種類は保護対象に合わせます。

**提出物：**保存またはネットワーク演習を行い、予測と実測を分け、権限と接続の問題を一つずつ説明します。削除は専用グループだけに限定します。
