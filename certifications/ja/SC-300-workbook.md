# SC-300 · アクセス判断とガバナンスのワークブック

[ガイド](SC-300.md) · [10ケース](SC-300-cases.md) · [目次](README.md)

架空の大学ノートアプリのための独自のオフライン五単元です。合成IDと文書を使います。テナントポリシーの変更、資格情報の作成、ロールのアクティブ化、本物のテレメトリ接続はしません。成果物は期待する判断を説明し、クラウド実行は主張しません。

<a id="sc-300-unit-1"></a>

## 1. 実効アクセスとIDの取得元をたどる

テナント、サブスクリプション、アプリ、文書ストアを図示します。ディレクトリロール、管理単位の範囲、Azureのリソースとデータのロール、アプリの権利を区別します。直接とグループ経由の付与経路を含め、メンバーシップの管理者を示します。ハイブリッドIDでは権威あるソースと、選んだ同期・認証の仮定を記録し、同期を権限付与と見なしません。

**シナリオ：**学生が直接割り当てを失っても授業フォルダーを読めます。**証拠：**二つの付与経路の候補と、それらを判別する記録を示す図です。**成果物：**学生、ゲスト、編集者、管理者、インデクサー、元メンバーの六行のアクセス判断表で、それぞれ最小範囲と期待する拒否を示します。

<a id="sc-300-unit-2"></a>

## 2. 認証と条件付きアクセスを設計する

対応する認証方式、登録経路、復旧責任者を指定します。フィッシング耐性と、実パスコードを保存せずTAPで対象者を初期登録できる箇所を説明します。ポリシーの対象、条件、許可・セッション制御、除外、ライセンスの仮定、緊急復旧を記載します。レポート専用評価と強制された結果を分けます。

**シナリオ：**客員教員は個人デバイスを使い、編集者は未公開解答を扱います。**証拠：**ID、認証方式、デバイス、リソースが異なる三つの要求予測です。テナント間クレームの信頼とアプリ権利を別々に説明します。**成果物：**ポリシー案の表と、試験導入、レビュー、復旧、切り戻し基準のある展開メモです。本物のテナントでは何も有効化しません。

<a id="sc-300-unit-3"></a>

## 3. ワークロードIDを選び、制約する

インデクサー用のアプリ登録、サービスプリンシパル、マネージドIDを比較します。委任とアプリケーションの許可、同意、リソース範囲を説明します。架空の外部ビルドについて、架空の値で期待するissuer、subject、audienceを記録します。トークンの発行成功がデプロイ権限を証明しない理由を述べます。

**シナリオ：**インデクサーは公開ノートのみを読み、ビルドは自分のテストアプリだけを更新します。**証拠：**ワークロードごとに許可と拒否の操作一つずつ、権限所有者、レビュー日を示します。**成果物：**IDの選択表とフェデレーション信頼の図です。パスワード、クライアントシークレット、実トークン、デプロイコマンドを含めません。裏付けのない仮定は所有者への質問として残します。

<a id="sc-300-unit-4"></a>

## 4. 権利と特権のライフサイクルを作る

PIMの資格、アクティブ化、有効期間を、定期的なアクセスレビューと区別します。客員教員向けアクセスパッケージと、入職、異動、退職に対応したライフサイクル自動化を提案します。SSOフェデレーションとSCIMプロビジョニングを分け、後続システムの削除確認を説明します。機能別ライセンスの仮定と、自動化失敗の責任者を列挙します。

**シナリオ：**教員の学期が終わる一方、管理者には一時的な保守権限が必要です。**証拠：**期限切れ判断、リソース所有者のレビュー、範囲付きのアクティブ化提案、後続プロビジョニングの完了記録です。**成果物：**トリガー、承認者、権利、期間、レビュー、期待削除、証拠、例外処理の管理表です。レビュー完了はロールのアクティブ化の証明ではありません。

<a id="sc-300-unit-5"></a>

## 5. 限定された証拠で失敗を説明する

ユーザーリスク、サインインリスク、ポリシー評価、ディレクトリ変更、プロビジョニング失敗を分けます。適切なログを選び、診断転送、保持、アクセス、スキーマの仮定を記述します。ガイドの仮のKQLに、集計で分かることと分からないことを注記します。Private Access、Internet Access、Microsoftトラフィックプロファイルは、リソース経路にその用途が関係するときだけ追加します。

**シナリオ：**ゲストは授業を開けませんが、画面には一致する失敗がありません。**証拠：**仮の時系列、可視性の穴、相関フィールド、競合する二つの説明です。**成果物：**ID、ネットワーク経路、ポリシー、アプリ権利、プロビジョニングを結ぶ一ページの診断と証拠一覧です。すべての結果を予測と明記し、クエリやテナントテストは実行しません。
