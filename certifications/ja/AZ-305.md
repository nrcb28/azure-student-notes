# AZ-305 · 認定試験

[目次](README.md) · [English](../en/AZ-305.md)

試験分野と比率は、2026年10月27日に確認した英語の公式ガイドに基づきます。試験の言語や実施日により変更があるため、受験前に確認してください。独自の学習用解説であり、すべての出題を網羅すると保証しません。

## 学習の狙い

要件を、費用と制約が明示された設計に変えます。ID・ガバナンス・監視 25–30%、データ 20–25%、事業継続 15–20%、インフラ 30–35%。目標は2026年4月17日からです。

確認した公式ページでは、Solutions Architect Expert に Azure Administrator Associate も必要です。試験合格と認定取得を同一視しません。

## 要件から始める

同時利用者、増加、データの所在、機密性、RTO/RPO、予算、運用能力を確認します。常時利用可能という表現だけでは測れません。

請求、管理、寿命の境界を分けます。ワークロードには適切なマネージド ID を使い、管理者の恒常的な特権を抑えます。Key Vault にもアクセス、更新、障害時の設計が必要です。

## データと処理

DB は問い合わせ、トランザクション、互換性、復旧要件で選びます。JSON だけでは決まりません。読み取りレプリカは書き込み能力を自動で増やしません。

キャッシュには失効、無効化、古い値の許容が必要です。小さいチームではモジュール化した単一アプリが扱いやすい場合もあります。キューは遅い処理を分離しますが、状態やエラーが増えます。

## 復旧、ネットワーク、移行

RTO と RPO は独立です。VM を複製しても DNS や秘密がなければ復旧できません。Active-active と active-passive は要件と運用で比較します。

グローバル Web、地域内 Web、L4、DNS を区別します。Hub-spoke にも戻り経路と名前解決が必要です。

**提出物：**依存関係を棚卸しし、試行、初回転送、変更の同期、切り替え、戻し方を設計します。計算と復旧の ADR を二つ書き、代案と見直し条件を示します。
