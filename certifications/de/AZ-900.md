# AZ-900 · Zertifizierungen

[Inhalt](README.md) · [10 Fälle](AZ-900-cases.md) · [English](../en/AZ-900.md)

Unabhängige Lernunterlagen. Bereiche und Gewichtungen stammen aus den offiziellen englischen Leitfäden, geprüft am 27. Oktober 2026. Vor der Prüfung erneut kontrollieren. Keine Bestehensgarantie und keine offiziellen oder vertraulichen Prüfungsfragen.

## Ziel und Aufbau

Wir erklären Begriffe und wählen Dienste anhand von Anforderungen. Produktnamen auswendig zu kennen reicht nicht.

| Bereich | Gewichtung |
|---|---|
| Cloud-Konzepte | 25–30 % |
| Architektur und Dienste | 35–40 % |
| Verwaltung und Governance | 30–35 % |

Zugrunde liegende englische Prüfungsziele: **20. Juli 2026**.

## Verbrauch und Verantwortung

CapEx bezeichnet Kapitalinvestitionen, OpEx laufende Ausgaben. Cloud-Nutzung verändert nicht automatisch jeden Kostenpunkt: Lizenzen, Verträge und Personal bleiben relevant.

Notiere für jede Anwendung Microsofts und eigene Aufgaben. Auch SaaS lässt Verantwortung für Identitäten, Daten und Einstellungen. Sichere Rechenzentren verhindern keine unsichere Anwendungskonfiguration.

**Fall:** Eigene Linux-Kernelmodule werden benötigt. Eine VM bietet passenden Zugriff, eine Webplattform möglicherweise nicht. Bei einer gewöhnlichen API kann PaaS dagegen Wartung sparen.

## Die Dienste einordnen

Verbinde Regionen, Zonen, Abonnements und Gruppen mit ihrem Zweck. Ein Availability Set ist keine Mehrregionenarchitektur. Azure Virtual Desktop liefert virtuelle Desktops und Anwendungen.

Unterscheide Objekte, Dateifreigaben und Datenträger. AzCopy automatisiert Übertragungen; Storage Explorer bietet eine Oberfläche; File Sync unterstützt Synchronisierung und Caching in passenden Szenarien. Azure Migrate und Data Box lösen unterschiedliche Migrationsaufgaben.

## Zugang und Beobachtung

SSO verringert wiederholte Anmeldungen, MFA ergänzt Faktoren, kennwortlose Verfahren vermeiden Kennwörter in unterstützten Abläufen. Autorisierung bleibt nötig.

Policy setzt Bedingungen, RBAC gewährt Aktionen, Tags klassifizieren und Sperren begrenzen Verwaltungsänderungen. Purview unterstützt Datengovernance und Schutz; Arc erweitert Verwaltung auf unterstützte externe Ressourcen.

Advisor empfiehlt, Monitor beobachtet, Service Health informiert über Dienstprobleme. Informationen allein beheben keine Ursache.

## Kosten und Übung

GB-Speicherpreise bilden nicht die ganze Rechnung ab. Leseoperationen, Übertragung, Compute und Logs können hinzukommen. Ein Budget ist kein universeller Ausgabenschalter.

**Abgabe:** Zeichne die Lernunterlagen-App, wähle API und Speicher, definiere Anmeldung, Rolle und Policy. Begründe einen tolerierten Fehler und fünf Kostenbestandteile. Jeder Dienst im Diagramm braucht einen Zweck.
