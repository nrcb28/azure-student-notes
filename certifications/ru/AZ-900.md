# AZ-900 · Сертификации

[Содержание](README.md) · [10 ситуаций](AZ-900-cases.md) · [English](../en/AZ-900.md)

Независимые учебные материалы. Области и веса основаны на официальных английских руководствах, проверенных 27 октября 2026 года; перепроверь их перед экзаменом. Нет гарантии сдачи и нет официальных или закрытых экзаменационных вопросов.

## Цель и структура

Нужно объяснять понятия и выбирать сервис по требованию. Одного запоминания названий недостаточно.

| Область | Вес |
|---|---|
| Понятия облака | 25–30 % |
| Архитектура и сервисы | 35–40 % |
| Администрирование и управление | 30–35 % |

Английские цели действуют с **20 июля 2026 года**.

## Потребление и ответственность

CapEx относится к капитальным вложениям, OpEx — к текущим расходам. Облако не меняет автоматически все затраты: лицензии, договоры и команда по-прежнему важны.

Для каждой нагрузки перечисляем задачи Microsoft и собственные. Даже SaaS оставляет нам управление удостоверениями, данными и настройками. Безопасный дата-центр не исправляет небезопасную конфигурацию приложения.

**Случай:** нужны собственные модули ядра Linux. VM даёт необходимый контроль, а веб-платформа может его не предоставлять. Для стандартной API PaaS способна уменьшить обслуживание.

## Карта сервисов

Связываем регионы, зоны, подписки и группы с их назначением. Availability set — не несколько регионов. Azure Virtual Desktop предназначен для виртуализированных рабочих столов и приложений.

Различаем объекты, файловые ресурсы и диски. AzCopy автоматизирует передачу, Storage Explorer даёт интерфейс, File Sync поддерживает синхронизацию и кэширование в совместимых сценариях. Azure Migrate и Data Box решают разные задачи миграции.

## Доступ и наблюдение

SSO сокращает повторные входы, MFA добавляет факторы, passwordless использует совместимые методы без пароля. Авторизация всё равно нужна.

Policy задаёт условия, RBAC разрешает действия, теги классифицируют, блокировки ограничивают операции управления. Purview относится к управлению и защите данных, Arc расширяет администрирование совместимых внешних ресурсов.

Advisor рекомендует, Monitor наблюдает, Service Health сообщает о проблемах сервисов. Информация сама не исправляет причину.

## Стоимость и практика

Цена гигабайтов не равна всему счёту. Учитываем чтения, передачу, вычисления и журналы. Бюджет предупреждает, но не задаёт универсальный предел расходов.

**Результат:** нарисуй учебное приложение, выбери API и хранилище, определи вход, роль и политику. Объясни один допустимый отказ и пять составляющих стоимости. У каждого сервиса должна быть причина.
