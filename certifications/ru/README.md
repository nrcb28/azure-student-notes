## С чего начать

AZ-900 даёт общую карту. DP-900 объясняет данные и нагрузки перед DP-300. SC-900 охватывает безопасность, идентификацию и соответствие требованиям также в Microsoft 365. AZ-104 даёт операционную основу для AZ-700, а AZ-305 и AZ-400 добавляют проектирование и поставку. Это советы по обучению, не официальные обязательные условия.

## Что добавлено

DP-900, SC-900, AZ-700 и DP-300 содержат равноценные объяснения, случаи и задания на всех восьми языках. Старые дополнительные конспекты других маршрутов сохраняют разный объём. По 80 сценариев на язык, всего 640 языковых вариантов; это не реальные экзаменационные вопросы.

## Повторение с тренажёром

Тренажёр самооценки поддерживает все восемь маршрутов и экспорт случаев в Anki. Сравни своё объяснение с ответом и оцени воспоминание. Мини-тест с выбором ответа сохраняет восемь вопросов по четырём исходным маршрутам.

```bash
python tools/study.py demo --lang ru --exam DP-900
python tools/study.py study --lang ru --exam AZ-700 --limit 5
python tools/study.py export --lang ru --exam SC-900 --output exports/ru-sc900.tsv
```

## Источники и ограничения

Исходные ссылки проверены 27 октября 2026 года, четыре новых маршрута — 30 октября 2026 года. Перед записью проверь цели, доступность, язык и требования на Microsoft Learn. Код экзамена и сертификация различаются; Expert-сертификации могут требовать другие удостоверения. Гарантии сдачи и заявления о выполнении в Azure нет.
