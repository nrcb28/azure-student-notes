# AZ-104 · 八语共同进阶练习册

[←](README.md) · [共同学习核心](../../zh/16-common-core.md) · [进阶实验](../../zh/17-advanced-labs.md)

八种语言具有对应的目标、案例和交付物。按学习单元及验证证据检查等价性，而不是比较字数。原有指南仍作为补充说明保留。

<a id="az-104-unit-1"></a>

## 1. 追踪有效访问

记录身份、租户、订阅、资源、操作和作用域。检查组、直接与继承分配、条件及传播。区分管理和数据操作，分配角色本身需要权限。

**案例：**能创建 Storage，不能列出 Blob。**证据：**所需权限及同一身份的最小检查。不以 Owner 作为通用测试，也不在没有假设时修改网络。

<a id="az-104-unit-2"></a>

## 2. 保护与恢复数据

分别为对象、容器、账户选择保护，记录事故前配置。启用版本后可能需要选择或提升某版本，不能假设所有配置恢复步骤相同。

**案例：**删除实验文件后原样恢复。**证据：**此前配置、前后 hash、权限检查，以及清理后仍保留的数据。

<a id="az-104-unit-3"></a>

## 3. 修改前读懂基础设施

分析参数、资源、依赖、输出和差异，区分编译、验证、what-if 和应用。导出配置可能需要加工，配额、区域和策略也会阻止语法正确的部署。

**案例：**what-if 无法分析模块。**证据：**诊断、未评估范围及应用前解决决定。修改 VM 时检查磁盘、网络和设置。

<a id="az-104-unit-4"></a>

## 4. 诊断完整路径

依次跟踪 DNS、IP、路由、NSG、系统防火墙、监听进程和应用授权。多个有状态过滤可能共同作用。检查 frontend、backend、规则和 probe，区分 App Service 私有入站与出站集成。

**案例：**probe 健康但真实请求失败。**证据：**端口、响应、有效规则和可验证假设。Probe 不证明业务正确。

<a id="az-104-unit-5"></a>

## 5. 按证据运维

定义指标、日志、告警、动作和负责人。查询前检查采集源、关联和目标。测量包含身份、DNS、依赖的完整应用恢复。

**交付：**Storage 与角色检查实验，预期对比观察结果及恢复 runbook。区分本地检查和 Azure 测试，确认删除或残余保留。
