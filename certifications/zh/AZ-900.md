# AZ-900 · 认证考试

考试领域和权重依据2026年10月27日核查的官方英语指南。不同考试语言和日期可能有更新，请在报考前确认。这是独立学习材料，不保证覆盖全部考题或通过考试。

## 学习目标

重点是说明需求与选择，而不是记住产品名称。云概念占25–30%，架构与服务35–40%，管理与治理30–35%。参考目标自2026年7月20日起适用。

## 消费模式与责任

CapEx 是资本支出，OpEx 是运营支出。上云不会自动消除人员、许可证和合同费用。

为 IaaS、PaaS、SaaS 分别列出自己的责任。需要修改 Linux 内核时考虑 VM；普通 API 则可通过 PaaS 减少维护。

区分区域、可用区、订阅和资源组。Availability set 不等于多区域。Azure Virtual Desktop 面向虚拟桌面和应用交付。

## 数据、身份与管理

比较 Blob、Files、Disks。AzCopy 自动化传输，Storage Explorer 提供图形界面，File Sync 支持兼容环境中的同步和缓存。Azure Migrate 与 Data Box 处理不同迁移场景。

SSO、MFA 和无密码登录不代替授权。RBAC 管操作权限，Policy 管资源条件，标签负责分类，锁保护部分管理操作。

Advisor 给建议，Monitor 提供观测，Service Health 说明服务事件。预算不会自动停止全部费用。

**交付：**画出笔记应用，解释计算、存储、身份、策略选择，列出五项成本和一种可容忍故障。图上的每个服务都要有理由，不把部署成功当作用户功能正确的唯一证据。
