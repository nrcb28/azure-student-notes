# AZ-104 · 认证考试

[目录](README.md) · [English](../en/AZ-104.md)

考试领域和权重依据2026年10月27日核查的官方英语指南。不同考试语言和日期可能有更新，请在报考前确认。这是独立学习材料，不保证覆盖全部考题或通过考试。

## 学习目标

管理员要配置、预测结果、验证并排错。身份与治理20–25%，存储15–20%，计算20–25%，网络15–20%，监控与维护10–15%。参考目标自2026年4月17日起适用。

## 身份与治理

Entra 目录角色不同于 Azure RBAC。用户管理员不会自动成为订阅 Owner。

权限仍存在时检查实际身份、组成员、直接和继承分配。NotActions 不是全局拒绝，另一角色可能再次授予操作。

先在有限范围审计 Policy，确认修正所用身份及权限。Deny 不会自动修复现有配置。

## 存储、计算与网络

分开检查网络、身份验证和数据授权。Contributor 不一定能读取 Blob。SAS 类型影响期限和撤销方式。版本和保留期要提前设计。

掌握 VM 大小、磁盘、网卡和路径，不将临时磁盘视为持久存储。App Service 的域名、DNS、证书和 TLS 分别检查；slot 可能共享依赖。

VNet integration 处理出站访问，不自动将入站变成私有。NSG 先评估较小优先级。排查 Load Balancer 时检查 frontend、backend、规则和 probe。

## 维护与实验

明确日志目的地、信号、告警和 action group。备份成功不保证 RTO，必须测量完整恢复。根据受保护负载选择 vault，而不是只看名字。

**交付：**完成存储或网络实验，区分预期和观察结果，各解释一个权限问题与连接问题，最后只删除专用实验组。验证文件能够恢复，不仅验证存在一个备份任务。
