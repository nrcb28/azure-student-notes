# SC-200 · 决策与证据练习册

[指南](SC-200.md) · [十个案例](SC-200-cases.md) · [目录](README.md)

针对虚构大学笔记应用的五个原创单元。使用编造的记录和标识符离线练习。分别标注预期结果和练习中提供的观察结果。不要求也不声称访问租户、部署云资源、执行实时查询、投递消息或开展遏制。

<a id="sc-200-unit-1"></a>

## 1. 映射收集和访问边界

画出 Microsoft 365、一个 Azure 应用、一台本地服务器和校园防火墙。在适当位置安排 Defender XDR 调查或 Sentinel 收集与分析。为每个来源规定接入、连接器前提条件、预期表和时间列、稳定标识符、延迟、保留期及负责人。区分读取、事件管理、规则编写和自动化权限。

**场景：**防火墙连接器似乎已连接，但所需事件缺失。**证据：**一张四来源覆盖表、一个收集运行状况问题，以及一个包含预期架构的合成事件。**交付物：**一张图和缺口清单，解释分析人员能够得出什么结论。加入个人数据和导出的处理规则；不要收集真实学生信息。

<a id="sc-200-unit-2"></a>

## 2. 建立经得起检验的事件时间线

虚构六条记录，覆盖邮件、身份、终结点、应用和云工作负载。为每条记录提供 UTC 事件时间、摄取时间、来源 ID、实体标识符和观察结果。将相关警报归组为拟议事件，但不要假定共享校园 IP 就能证明关联。区分已知范围、怀疑范围和不可用遥测。

**场景：**一条可疑消息出现在疑似私人文档访问之前。**证据：**时间线、实体图、其他可能解释，以及一条请求补充的缺失记录。**交付物：**分诊说明，包含负责人、优先级理由、拟议遏制、授权要求、服务影响和恢复条件。将每项拟议操作标为未执行；预期确认不是已观察到的响应。

<a id="sc-200-unit-3"></a>

## 3. 相信计数之前先解释查询结果

阅读指南中固定的合成 KQL 数据集。追踪行如何经过半开 UTC 窗口、Denied 筛选、去重和聚合。解释为什么预期答案是 `student-a` 的两个事件。再添加一张虚构表，其中包含该账户的两行记录，并画出显式内部联接产生的配对。与默认 `innerunique` 对左侧去重的行为进行对比。

**场景：**报告把联接后的行误认为独立攻击。**证据：**中间行数、联接键、标识符假设及一个边界时间示例。**交付物：**更正后的解释，包含预期输出和局限。不声称执行过查询；可选的本地计算也应与租户观察结果区分。

<a id="sc-200-unit-4"></a>

## 4. 把搜寻假设转化为检测调整评审

编写一个将收到可疑消息与异常私人文件访问联系起来的假设。定义群体、UTC 窗口、所需来源和另一种解释。创建四个已标注正常、四个可疑的合成示例。提出一项检测和一项范围狭窄的例外，再指出哪些示例会触发警报、被遗漏或需要更多上下文。解释 ASIM 如何规范化兼容来源，以及哪些解析器映射需要验证。

**场景：**已授权的导入看起来像滥用。**证据：**版本化决策表、来源缺口、误报和漏报分析，以及解析器映射检查。**交付物：**一项调整建议。搜寻结果为空和警报更少，都不能证明没有入侵或覆盖完整。

<a id="sc-200-unit-5"></a>

## 5. 评审辅助响应工作流

画出一条调用操作手册来丰富信息，并在有干扰性的遏制前请求审批的自动化规则。分别识别操作人员、Sentinel 调用权限、工作流身份和下游范围。模拟重复触发及超时；记录防止重复工单或不必要重复限制的标识符和状态检查。加入负责人和恢复条件。

**场景：**AI 摘要在缺少应用日志的情况下，将云警报与学生下载联系起来。**证据：**论断与来源对照表、更正后的结论、审批边界和预期重试行为。**交付物：**已评审的桌面推演运行手册。根据所提供的记录和查询语义核实 Copilot 建议。不发送通知、审批请求或真实响应。
