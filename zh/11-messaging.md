# 消息与事件

[目录](README.md) · [认证考试](../certifications/zh/README.md)

队列将发送和处理解耦。Storage Queues 适合简单工作队列，Service Bus 提供队列与主题，Event Grid 分发事件，Event Hubs 接收大规模事件流。它们并非自动可互换。

处理完成但确认失败时，同一消息可能再次出现。消费者应使用稳定标识和一致性更新，避免重复副作用。

**缩略图例子：**消息包含文档 ID，消费者检查已有结果，再生成、保存并确认。还要考虑并发消费者及哪些步骤必须原子化。

同时监控消息数量和最老消息年龄。数据库是瓶颈时，增加消费者可能使情况更糟。顺序保证、死信和失败重试取决于具体服务及配置。
