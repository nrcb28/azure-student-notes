Download the raw file and import it into Anki. Map the first column to Front, second to Back, and third to Tags; preview before confirming. Supported Anki versions can read the included separator, HTML, and tags-column headers.

Descarga el archivo en formato raw e impórtalo. Comprueba Front, Back y Tags en la vista previa. Las versiones compatibles leen las cabeceras incluidas.

These decks contain repository cases, not official exam questions. Anki schedules independently from the local trainer. They include no learner progress.

Contienen casos propios, no preguntas oficiales. Anki programa sus repasos por separado y los mazos no contienen progreso personal.
