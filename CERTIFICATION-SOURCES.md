Explanations, scenarios, and deliverables are original study material. They are neither real exam questions nor exhaustive coverage of every subobjective.

## DP-900 · Datos / Data

[Certificación asociada / Associated certification](https://learn.microsoft.com/en-us/credentials/certifications/azure-data-fundamentals/). Preparación conceptual para diferenciar representación, transacciones y análisis; no es un prerrequisito obligatorio de DP-300. / A conceptual introduction to data representation, transactions, and analytics, rather than a mandatory DP-300 prerequisite.

- [Azure SQL deployment options](https://learn.microsoft.com/en-us/azure/azure-sql/azure-sql-iaas-vs-paas-what-is-overview): responsibility and compatibility boundaries.
- [Azure Storage introduction](https://learn.microsoft.com/en-us/azure/storage/common/storage-introduction): storage services and workload fit.
- [Cosmos DB overview](https://learn.microsoft.com/en-us/azure/cosmos-db/overview): conceptual non-relational service choices.
- [ETL and ELT](https://learn.microsoft.com/en-us/azure/architecture/data-guide/relational-data/etl): transformation order and operational consequences.
- [Microsoft Fabric overview](https://learn.microsoft.com/en-us/fabric/fundamentals/microsoft-fabric-overview): analytics platform context.

## SC-900 · Seguridad, identidad y cumplimiento / Security, identity, compliance

[Certificación asociada / Associated certification](https://learn.microsoft.com/en-us/credentials/certifications/security-compliance-and-identity-fundamentals/). Incluye Azure y Microsoft 365; cada control necesita ámbito, señales, responsables y capacidades compatibles. / Covers Azure and Microsoft 365; controls need scope, signals, owners, and supported capabilities.

- [Zero Trust](https://learn.microsoft.com/en-us/security/zero-trust/zero-trust-overview): explicit verification, privilege boundaries, and compromise assumptions.
- [Conditional Access](https://learn.microsoft.com/en-us/entra/identity/conditional-access/overview): policy evaluation and access requirements.
- [Privileged Identity Management](https://learn.microsoft.com/en-us/entra/id-governance/privileged-identity-management/pim-configure): eligible and time-bound privilege.
- [Defender XDR](https://learn.microsoft.com/en-us/defender-xdr/microsoft-365-defender): correlated signals across onboarded products.
- [Microsoft Sentinel](https://learn.microsoft.com/en-us/azure/sentinel/overview): SIEM and response orchestration.
- [Microsoft Purview](https://learn.microsoft.com/en-us/purview/purview): protection, governance, and compliance capabilities.

## AZ-700 · Redes / Networking

[Certificación asociada / Associated certification](https://learn.microsoft.com/en-us/credentials/certifications/azure-network-engineer-associate/). El recorrido de una petición incluye nombres, rutas, filtros, escucha y autorización. / A request depends on names, routes, filters, listeners, and authorisation.

- [VNet peering](https://learn.microsoft.com/en-us/azure/virtual-network/virtual-network-peering-overview): connectivity and transit design.
- [Azure routing](https://learn.microsoft.com/en-us/azure/virtual-network/virtual-networks-udr-overview): effective routes and custom routes.
- [Private endpoint DNS](https://learn.microsoft.com/en-us/azure/private-link/private-endpoint-dns): resolving the intended private destination.
- [ExpressRoute encryption](https://learn.microsoft.com/en-us/azure/expressroute/expressroute-about-encryption): connectivity and encryption are separate requirements.
- [Load-balancing options](https://learn.microsoft.com/en-us/azure/architecture/guide/technology-choices/load-balancing-overview): service scope and supported protocols.
- [Network Watcher](https://learn.microsoft.com/en-us/azure/network-watcher/network-watcher-overview): evidence for connectivity diagnosis.

## DP-300 · Administración SQL / SQL administration

[Certificación asociada / Associated certification](https://learn.microsoft.com/en-us/credentials/certifications/azure-database-administrator-associate/). El éxito incluye acceso, rendimiento, datos correctos y recuperación comprobable. / Success includes access, performance, correct data, and verifiable recovery.

- [Azure SQL platform comparison](https://learn.microsoft.com/en-us/azure/azure-sql/azure-sql-iaas-vs-paas-what-is-overview?view=azuresql): platform responsibilities and compatibility.
- [SQL Database security](https://learn.microsoft.com/en-us/azure/azure-sql/database/security-overview?view=azuresql): layered protection and access.
- [Query Store](https://learn.microsoft.com/en-us/sql/relational-databases/performance/monitoring-performance-by-using-the-query-store?view=sql-server-ver17): plan and execution history.
- [Job automation](https://learn.microsoft.com/en-us/azure/azure-sql/database/job-automation-overview?view=azuresql): choosing supported scheduling mechanisms.
- [Recovery using backups](https://learn.microsoft.com/en-us/azure/azure-sql/database/recovery-using-backups?view=azuresql): restoring retained data states.
- [Business continuity](https://learn.microsoft.com/en-us/azure/azure-sql/database/business-continuity-high-availability-disaster-recover-hadr-overview?view=azuresql): availability and disaster-recovery design.

Las fuentes oficiales pueden cambiar sin que cambien estos apuntes.

Technical references were read to check concepts, not to reproduce complete articles. This record establishes no deployment, operational testing, pricing, tenant licensing entitlement, or professional translation certification. Official sources can change independently of these notes.
